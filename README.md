# Trade-In Negotiation Lab — free public demo

This is a self-contained HTML prototype. It runs locally and on GitHub Pages without hosting fees, API keys, Python, or external network calls. It simulates three agent roles with explicit JavaScript rules; **it does not use a live language model**. All amounts are hypothetical.

## Publish on GitHub Pages
1. Sign in to GitHub and create a **public** repository (e.g. `tradein-negotiation-demo`).
2. Upload `index.html` to the root of the repository, and commit it.
3. Open repository **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to show the public site URL. It typically looks like `https://YOUR-USERNAME.github.io/tradein-negotiation-demo/`.
5. Open the actual generated URL and test Demo A and Demo B before adding it to the slides.

Do not upload real dealership or customer data. There is no login or access control.
